# Agentic Distributed Harness Depot (ADHD)

The canonical full product name is Agentic Distributed Harness Depot. Its acronym
is ADHD and its existing technical namespace is adhd. Depot is the agreed final
word of the name. Generic terms such as hub, information hub, coordination and
database remain appropriate descriptions of functions and storage technology.

Use the full expansion in the browser document title and visible sign-in heading.
The title is exactly `ADHD | Agentic Distributed Harness Depot`. The sign-in
heading is exactly `Agentic Distributed Harness Depot`. In the authenticated
console keep the compact ADHD brand with the full expansion visibly available
in its desktop brand subtitle or an about/introduction area. Keep the existing four
views, labels and interactions while adding the Settings, Users and Agents views
required by configuration/spec.md and identity/spec.md. Fit the long name on desktop and 390px mobile
without document overflow, truncated words or overlapping controls. Preserve the
existing operations-workspace design; no visual redesign is required.

The public Agent Card keeps name `ADHD` and uses description
`Agentic Distributed Harness Depot (ADHD): a private A2A information hub for agent coordination.`
All other Agent Card protocol, capability, bearer authentication and skill fields
remain governed by component.md. This is a presentation update only.

Preserve the exact existing CLI describe JSON, including name `ADHD`, version,
protocol and operations; do not add display_name or other fields to that response.
Keep the existing command-line forms, HTTP routes, JSON field names, domain codes,
adhd.hub error domain, IDs, configuration names, storage schema and migration
behavior. Do not rename directories, containers, images or client identities, or
change authentication or matching merely for naming. Authentication and live
configuration changes are now explicitly owned by identity/spec.md and
configuration/spec.md. No new CLI help operation is required; project
helper script help and product documentation supply the full name.

Native tests must retain coverage of real durable transitions, original schema-2
source-event retries, schema-1 upgrades, private visibility, admin mutations and
model error handling, rather than replacing behavior tests with naming assertions.
Verifier-owned vectors stay independent of native manifest cases. Qualification
must exercise unchanged describe output, the named Agent Card fields and browser
presentation, with existing client and container acceptance remaining compatible.
